Privacy notice

Effective 17 October 2026 · Operator: Shivam Kumawat

This notice describes the data practices for Organic Growth MCP, a personal desktop Google API workflow. The public information site and the local MCP integrations perform different roles.

Data accessed and purpose

With account authorization, the desktop workflow can access Search Console property identifiers, permissions, queries, pages, clicks, impressions, average position, sitemap information and URL Inspection results. It can also access Analytics account/property information, reporting metadata and requested report results, including traffic, events, conversions or revenue where available and requested.

The workflow uses those data for the operator’s requested SEO research, technical diagnostics, reporting and measurement. Access must be limited to properties and tasks the operator is authorized to handle. It does not request Gmail, Drive or payment-account permissions.

Permissions and actions

Search Console uses https://www.googleapis.com/auth/webmasters, which includes write access for sitemap submission as well as reading Search Console data. Sitemap submission requires an explicit operator request. Analytics uses https://www.googleapis.com/auth/analytics.readonly; the app does not change Analytics settings through this connection.

Local storage and retention

The desktop configuration stores OAuth client information and refresh tokens in local files restricted to the operating-system user. File permissions are not a promise of application-level encryption or hardware-backed secret storage. The operator is responsible for device security, backups and access controls.

Requested data can be retained in assistant conversations, local evidence registers, exports, reports or backups. There is no automatic deletion schedule configured for the current local workspace. Keep only data necessary for the authorized task, review retention regularly and remove unneeded local copies. Deleting a local export does not necessarily delete assistant-provider or backup copies.

AI-assisted processing and service providers

MCP results supplied to the configured AI assistant may be transmitted to and processed by its service provider. The current workflow uses Codex from OpenAI. The operator must use account settings and contractual terms compatible with the Google API data being processed, and obtain any necessary property-owner permission. Do not supply sensitive personal data, credentials or unnecessary user-level information to an assistant.

Google API data must not be used to develop, improve or train generalized AI or machine-learning models. Do not enable provider data sharing for that purpose. Provider retention and processing are governed by the actual account, settings and applicable terms; this notice does not promise zero retention, a particular training setting or a particular geographic processing location.

Other integrations must not receive Google data without an appropriate disclosed purpose and authorization. This notice does not authorize public sharing, unrelated outreach, sale of data or transfer to advertising platforms or data brokers.

Google API Limited Use

Organic Growth MCP’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements. This is an operator commitment, not a claim that Google has verified or endorsed this app.

The public information website

These static pages contain no app-added analytics, advertising, external fonts, tracking scripts, sign-in forms or OAuth callback handler. No Google credentials or private reporting data are included in the published files.

GitHub Pages hosts this site. GitHub may process visitor information, including IP addresses, for hosting and security under the GitHub Privacy Statement. The site is therefore not described as collecting no data at all.

Revoke access or request removal

You can review or revoke this app’s access from Google Account connections. Revocation stops future API access through the affected authorization; it does not erase previously retrieved reports or conversations.

The operator can remove local credentials and data, and use the configured assistant provider’s controls for retained conversations. For non-sensitive questions, use the public issue tracker. For private requests, use the support email displayed on the app’s Google consent screen. Do not put private data or tokens in an issue.

Changes

Update this notice before introducing a materially different purpose, provider, permission or data flow. Obtain renewed consent where required. The effective date above identifies the current notice.
