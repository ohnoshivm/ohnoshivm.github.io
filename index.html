Your search data, in a deliberate workflow.

Organic Growth MCP is a personal desktop setup maintained by Shivam Kumawat. It connects authorized Google Search Console and Google Analytics properties to an AI-assisted SEO research and reporting workflow.

This site explains the app and its data practices. It is not a hosted analytics dashboard, a public SaaS product or a Google sign-in portal. It does not receive OAuth callbacks or store Google credentials.

What the desktop app does

  • Lists Google properties the signed-in account is permitted to access.
  • Reads Search Console performance, sitemap and URL Inspection data when requested.
  • Reads Google Analytics account information and reports for authorized properties.
  • Supplies requested results to the operator’s AI assistant for SEO analysis, research and reporting.
  • Supports Search Console sitemap submission when the operator explicitly requests it.

Google permissions

ServicePermission and purpose
Search Consolewebmasters
Reads verified-site search and indexing information; also permits sitemap submission. This connection is not read-only.
Google Analyticsanalytics.readonly
Reads account/property information and requested reports. It does not permit Analytics configuration changes.

Connecting an account does not give the app access to properties that account cannot already access. Publishing this information site does not expose any connected property’s private data.

Understand the data flow

Google APIs → local MCP server → the configured AI assistant. Requested results can leave the computer when supplied to the assistant’s service provider, including OpenAI for the current Codex setup. This is not an entirely offline workflow.

Read the privacy notice for local storage, AI processing, hosting logs and revocation. Read the terms of use before using the setup.
